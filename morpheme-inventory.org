- {The qĩ'khan'leĩ'khĩm'TeiRĩBĩm take the 880 CV+CVC+CVV verbals+nounals

  then consider derived fi/thi/quae rows fused to their root TeiRĩBĩm
  resulting in no additions except 'Quae',
  then drop many of the obscure/debatable cases from the main 880,

Relations to pay attention to cross-checking:
- procession e.g.
  - rĩ 'speak, speech' -> rĩm 'vibration, harmony' -> imi {savor, significance} -> mĩr 'atmosphere'
  - ri 'speech' -> rin 'logic, reason' -> ini {factual structure} -> ni 'to be' -> nin 'thing, entity'
- adjunction e.g.
  - nin 'thing, entity' <-> ini {factual structure}
  - nim 'conscious being' <-> ini {factual structure} + imi {savor, significance}
  - mim 'dual interpretation' <-> imi {savor, significance}
- reversal e.g.
  - rĩm 'vibration' <-> mĩr 'atmosphere'
  - rin 'logic, reason' <-> nir 'illogic, obstinacy'
- consonant affiliation, e.g.
  - rĩf '{inner wind,} freedom' <-> lĩf 'outer wind, weather event'
- consonant derivation, e.g.
  - rit 'utterance, action' + rĩf '{inner wind,} freedom' -> rĩth 'breath, lungs'
  - hĩm 'herd-tie, affiliation' -> fĩm 'friendship'
- consonant fusion {more useful to analyze in derivation of Quaehĩrrh'rĩm vocabulary proper}, e.g.
  - osh 'ancient, enduring' + sha 'relation' -> osha 'elder {to someone else}'
  - ash 'teaching, wisdom' + sha 'relation' -> asha 'teacher {to someone else}'
  - {mi 'to do' / mif 'method'} + fi 'bring, attract' -> mifi- {'method-ing' / 'making use {of something}'}
