# ᙭ᑮᐤᕇᔅᑐᐧᐁᓕᐧ᙮ᑖᓕᓲ

For versions of Quaehĩrrh that are metaphysically close-enough to
versions of Aaurfeĩ, such that mutual dialogue could be conducted
through portal travel instead of reading tea-leaves and tossing Git
repositories over the fifth wall, the question of religious dialogue
is an inevitable one. Any time a new culture is discovered speaking a
new language, Christian missionaries like to translate the Gospel as a
preparation for mutual philosophical incomprehension.

Out of courtesy to missionaries and in keeping with the original
Aaurfeĩ applications of Canadian Syllabics, Quaehĩrrh'rĩm translations
of four Gospel verses are hereby provided for which mutual
incomprehension is likely to be minimal.

* * *

(M5:15) ᔭᐧᑫᑭᓂᒻ ᐁᕐᐧ᙮ᐯᐤᐲᕐ ᐆᕐᑌᐧᐱᒃᓓᓐ ᓀᐤᐧᕂᐤᒥᐅᓐ ᓄᐧᐊᕐᑕᐧ᙮ᐯᐤᐲᓓᒃ ᔭᕋᒻᐧᐊᐧ᙮ᕌᑕᓪᐧᕋᐄᓂᒻ ᙮ᐯᐤ᙮ᕇᒻᐧᑫᕐᔨ.  
(M5:15) ya'hekinim er'Peibĩr urte'pihlen neĩ'reĩmioh, no'arta'Peibĩleh yaram'a'Rautal'raĩnim BeiRĩm'keryi.

(M13:31) ᔭᐧ᙮ᑌᐤ᙮ᔑ᙮ᑮᕐᓛᐤᒻ ᓂᐊᓐᐧ᙮ᕠᓘᔥᐧᐃᓪᐲᐲᕝᓕ ᔭᐧᑭᓂᒻᐧᑌᕋᒻᐧᒉᐊᐧᓓᐃᕐᐧ᙮ᓛᐤᑕᕝᐧᑳᕂᑕᒻ  
(M13:32) ᕋᐃᕐᐧ᙮ᐲᕝ ᐁᔅᐧᕋᐄᐧᐲᕝ ᐊᕐ᙮ᐄᓪ ᒉᐧᓄ ᐊᐧᓓᐤᕖᕐᓛᐤᓐ ᙮ᐊᕐ᙮ᐋᐤ᙮ᓴᐃᐧᐁᓂᕆ ᐊᓐᐧ᙮ᐋᐤᕖᕐᐧᐊᓂᐊᒃ ᒉᐧᐁᔅᐧ᙮ᕌᐤᒦᕐ ᐁᕐᐧᒦᕐᓯᕖᑦᐧᐃᕐ ᐊᐧᓓᐃᕐᐧ᙮ᕖᕐ᙮ᓖᓐᐧᐊᕂᐧᒍᓘᔥᔨ.  
(M13:31) ya'TeiShiHĩrlaaum nian'Dhilush'ilbĩpĩfli ya'kinim'teram'chea'leir'Laautaf'hauretam:  
(M13:32) rair'Pĩf es'raĩ'pĩf arIl, che'no a'leĩfĩrlaaun ArAauSai'eniri an'Aaufĩr'aniah, che'es'Raaumĩr er'mĩrsifĩt'ir a'leir'FĩrLĩn'are'cholushyi.

(M22:37) ᙭ᐃᓴᐧᕇ «᙮ᐊᕐ᙮ᐋᐤ᙮ᑌᐤ᙮ᓂᒻ ᐊᐧ᙮ᕌᕞᕐᐧ᙮ᕌᖃᑌᐤᐧ᙮ᕌᕇᑭᑦ ᕖ᙮ᓱᔩ.»  
(M22:38) ᕋᐧ᙮ᖂ᙮ᔩ᙮ᕇ᙮ᓖᒻ ᓂᕆᐧᐊᕐ᙮ᐋᐤᐧᐊᕐᕖ.  
(M22:37) Isa'rĩ: «ArAauTeiNim a'Rauther'Rauqatei'Raurĩhit fĩSoyĩ.»  
(M22:38) ra'QuYĩRĩLĩm niri'arAau'arfĩ.

(M22:39) ᒉᐧ᙮ᑎᕖᐧ᙮ᖂ᙮ᔩ᙮ᕇ᙮ᓖᒻ ᓂᕆᐧ᙮ᐃᕝᓕᕖᐧᔭ «᙮ᕖᒥᕐ ᐊᐧᓓᐃᒻᐧᓓᐤᕖᐧᒥᕝ ᕖ᙮ᓱᔩ.»
